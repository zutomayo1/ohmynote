## 关系图谱全面升级（bb4d94d，本次最大改动）
**零依赖原则下「借鉴开源」= 借算法与交互，不引库**：参照 graphology-communities-louvain /
graphology-layout-forceatlas2 / d3-force / force-graph / sigma.js / Obsidian-Quartz 的局部图。

### 算法（app/services/graph.py，新增）
- **Louvain 纯 Python 实现，两个必须做对的点**：
  1) 迭代顺序按度降序（确定性，同输入同结果）；
  2) **候选必须包含「留在原社区」，且仅在严格更优（> best + 1e-12）时移动** ——
     只比较「搬到邻居社区」的收益会让对称图（三角形/两个等大团）里节点反复搬家，
     `while improved` 永不退出 → **进程挂死**（本轮实际踩到，表现为命令 SIGTERM 无输出）。
  另加每层最大扫描轮数（_MAX_PASSES=50）做防御。
- 社区 id 按规模降序返回，前端「前 8 簇各配一色」。
- ego_graph：1–2 跳，超过 max_nodes(60) 按「子图连通度降序 + 最近更新」截断并标 truncated。
- `tag_color` 上移到 `utils.py` 成唯一实现（模板过滤器 + 图谱节点同源 ⇒ 同标签同色）。

### 前端（graph.js 重写为 GraphView.create 引擎，全局页与局部图共用）
- **互链边判断必须用单独的有向表**：adj 是无向的（高亮用），拿它判断 A→B 与 B→A 会把
  每条边都当互链（e2e 抓到 31/31 全变曲线）。
- **不要用 setPointerCapture**：捕获后 click 派发到 <svg>，节点 <g> 上的 click 永远收不到
  （表象：点节点不跳转）。改为 pointermove 挂 document。
- **拖完节点会被弹簧拽回原位**（拖了等于没拖）→ 松手后把该节点 `pinned` 短程松弛（alpha 0.2/800ms），
  松弛结束解除。修复前净位移 +2px、修复后 +34px。
- 位置记忆按 note id 存 localStorage；**恢复时用低 alpha(0.35) 只做局部微调**，
  否则会把用户熟悉的布局重揉一遍（漂移 5–22px vs 重排 100+px）。
- 搜索时**临时忽略「只看有链接」**，否则孤立笔记里的命中项永远找不到；未命中项变淡保留上下文。
- 性能：<200 节点精确两两斥力；≥200 走四叉树 Barnes–Hut（θ=0.5，实测相对误差 7.95%）。
  碰撞用网格加速 + **把标题真实宽度（getBBox）算进碰撞半径**（标签重叠是关系图最刺眼的问题）。
- 节点多的图（>55）先隐标题，悬停/选中/命中/中心才显示。

### 页面
- 笔记详情页侧栏局部图，**必须在 detail.html 的 scripts 块单独引 graph.js**
  （它不在 base.html 里，只在 graph.html 的 scripts 块 —— 漏了就是「容器在、一个节点都没有」）。
- build() 里要 `applyView()` 写一次 transform，否则未缩放前视图状态读不到（测试也断言不了）。
- `?focus=<id>` 定位；`?graph_depth=2` 看两跳（非法值一律退化 1 跳）。

### 验收手段（可复用）
- 造「两个 5 元团 + 桥 + 枢纽星 + 叶子 + 孤立点 + 一组互链」的合成库，一次覆盖度数缩放、
  聚类数、曲线边计数、搜索带出孤立点等全部新能力。
- **e2e 断言要只统计本测试造的节点**（临时库会带着用户真实笔记，绝对数量断言必假红）。
- 「等布局停稳」helper：连续两次采样 transform 一致再测量（否则读数时模拟还在跑，漂移假象）。
- 平移测试要先扫描出真正的空白点（布局紧凑时画布中心附近也可能是节点）。

## 图谱第三批：路径 / 图内建链 / 导出 / 布局参数 / 按分类着色（c2977f2）
### 产品侧取舍
- **路径查找**在「可见子图」上做 BFS（无向）：用户问的是「这两篇有没有关系」，方向次要。
  两个细节是必须的：① 只选了起点时**不要压暗其余节点**（否则看不清拓扑、没法选终点）；
  ② 路径高亮在 applyHighlight 里**优先于**选中/悬停高亮，否则两种高亮互相覆盖。
  路径模式下 Enter 语义从「打开笔记」切成「记端点」，要在提示行里写清楚（含 Esc 退出）。
- **图内建链**复用 link_note 的 `_resolve_link_target`，只把 303 换成 JSON；「已连过」返回
  ok=True+already=True（不是错误）——前端就不必为它弹红。建完调 `addLink()` **本地补边**
  （push + 度数 +1 + computeVisible + recomputePath + 重建 DOM），刷新前就能看到新连线。
### 导出图片（知识点集中）
- 页面样式在样式表里，序列化带不走 → **把 getComputedStyle 内联**到克隆副本
  （fill/stroke/font-*/opacity/text-anchor…），逐个 removeAttribute('class')。
- **顺序坑**：内联会删 class → 必须**先** querySelector('.graph-viewport') **再**内联。
- 视图组要去掉 transform（导出整张图，与当前缩放无关）；viewBox 用 `viewport.getBBox()`
  （getBBox 不含自身 transform，正好是图坐标）+ pad 留白。
- 必须铺一层背景色（透明背景贴到白底文档里节点就看不见）；背景从祖先里找第一个非透明
  backgroundColor，兜底读 `--surface`。
- PNG：data URL → Image → canvas（2×）→ toBlob。e2e 用 `page.expect_download()` 拿真文件，
  校验 `\x89PNG` + 解析 IHDR 宽高（比断言「点过按钮」强得多）。
### 真 bug（回归抓到的）
- **「钉住/拖拽」必须在所有力里豁免**：上一轮只挡了积分，**碰撞没挡** —— 刚放下的节点被邻居
  推走几十像素（净位移 +23px，本该 +44px）。碰撞里也要「按住的那个不动、只推邻居」。
  通则：**输入设备永远压过物理模拟**。改完 Barnes–Hut 精度 7.95% → 3.03%。
### 测试方法论
- **e2e 断言要数据驱动**：把「双向边 = 2 条弧线」改成从 `#graph-data` 自己算互链对数量
  （临时库带着用户真实笔记，用户新加的互链对会让写死的数字直接假红——这次就是这么红的）。
- `tag_color` 哈希是均匀的（4000 样本 466–523/桶），但**短中文词会撞色组**
  （甲类/乙类/丙类 全是 1）→ 测试数据要挑不同色组的名字，否则断言「三种颜色不同」必挂。
- 暗色主题用**数值断言**代替肉眼看截图：面板底色亮度 < 90、文字亮度 > 120。
