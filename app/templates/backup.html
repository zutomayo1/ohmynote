{{ icon('download', 18) }} 导出

导出的文件不依赖本工具，可以直接放进 Obsidian / Typora / VS Code 阅读。

{{ icon('download', 16) }} 下载 zip（Markdown 打包） {{ icon('download', 16) }} 下载 JSON（结构化）

zip 内含 index.md、notes/（每篇一个 .md）、 notes.json、README.txt。

{{ icon('upload', 18) }} 导入 / 恢复

  • 会按 slug（没有就按标题）匹配：匹配到就更新，匹配不到就新建。
  • 绝不删除备份里没有的笔记，也不会清空回收站。
  • 同一份备份导入多次不会翻倍。
  • 坏掉的条目会记进错误列表，其它条目继续导入。

{{ icon('history', 18) }} 数据库自动备份

用 SQLite 的一致性快照生成，应用开着也能安全备份（不是直接复制数据库文件）。 备份存在 data/backups/（{{ backups_dir }}）， 整个目录可以直接拷走。
